Se rehízo el borrado de datos personales de las epicrisis tras detectar que el procedimiento anterior dañaba el texto clínico: al eliminar el cargo TENS también mutilaba palabras como hipertensión. La nueva versión elimina identidades solo cuando aparecen como palabras completas, toma el nombre del paciente desde el encabezado del documento y cubre teléfonos, correos y datos de contacto, además de manejar las menciones negadas de la hemofiltración de alto volumen. La reconstrucción se validó sobre 28 documentos y luego sobre los 275 originales, generando la planilla y la base de datos desde una misma fuente. Se pusieron en cuarentena los resultados anteriores del cluster, se rehizo la cohorte de referencia de 20 casos y se preparó una entrega cifrada con inventario, diccionario de datos y huellas de verificación.
