Se desarrolló el pipeline de ingesta de documentos médicos (PDFs) hacia la base de datos PostgreSQL. Se implementaron mejoras críticas en los algoritmos de anonimización para el correcto manejo de preposiciones, iniciales y *placeholders*, garantizando la protección de datos sensibles. Además, se construyó la interfaz base de anotación clínica, integrando métricas de consistencia inter-evaluador (IRR), un sistema semáforo de dificultad y la guía oficial de anotación.
