Se implementó el ocultamiento de los datos que identifican al paciente al momento de entregar el documento al anotador, sin alterar los registros guardados, que conservan la información real para el equipo investigador. El reemplazo se acotó al RUT, la dirección, el nombre y las firmas médicas, y usa bloques del mismo largo que el texto tapado para que la página no se descuadre. Como el identificador almacenado no es legible, el nombre y el RUT se recuperan del propio texto del documento antes de taparlos. Se agregó una lista de términos médicos para evitar que expresiones clínicas fueran confundidas con firmas, y se ajustó la lectura de las firmas del cierre. Se corrigió además un error que dejaba caído el servicio de consulta de epicrisis.
